# SCF2026 紙マップ改訂稿

A4横・カラー・片面。店舗・観光21地点、イベント3件を掲載。
集合場所・集合時刻は未定のため、記入欄の値は空欄。

## 再生成

ReportLabを利用できるPythonで、リポジトリのルートから実行します。

```sh
python3 output/pdf/source/build_sakyu_map.py
```

店舗・イベントの元情報は `data/spots.json` と `data/events.json` を直接読み込みます。
原本JSON・Webページへの変更はありません。初稿内の短い注意文・イベント紹介は紙面用の要約です。
JSON更新時は、紙面用の要約との整合性とレイアウトも確認してください。
フォントはmacOSのArial Unicode / Arial Boldを埋め込んでいます。

## 地図

`osm-map-data.json` は、OpenStreetMapの小範囲の道路・建物等をOverpass APIから取得した地理データです。
データの時点は同ファイルの `osm3s.timestamp_osm_base` に記録されています。
OpenStreetMap contributors / ODbL: https://www.openstreetmap.org/copyright

Web用タイル画像は利用せず、取得したベクトル形状を紙面に描画しています。
点の座標はJSONのまま維持し、ラベルのみ引出線で分離しています。
特に09・10と02・Eは元データで同一座標です。
地図は情報を整理した印刷用表示です。歩行ルート・所要時間は案内していません。

## 確認

PDFは1ページ、A4横。全21地点の名称・全3イベント・重要注意事項をテキスト抽出で確認。
レンダリングしたPNGで、文字・地図番号・欄外へのはみ出しを確認。
レンダリング後のQRをZXingでデコードし、Web版URLとの一致を確認済み。
最終確認日は元JSONから取得し、制作日で上書きしません。
印刷時は「A4横・実際のサイズ（100%）」を推奨します。

## 今回のレイアウト改訂

飲食店の種類列・略記凡例の削除、SCF時間内列の幅104ptを維持。
馬の背（A）は地図から外し、観光一覧には残しています。
左側の地図欄内を、南北に長いエリアマップ250×371ptと密集エリア拡大図143×229ptに再配置。
エリアマップの表示範囲を店舗・施設が並ぶ範囲に絞り、両図とも前稿に比べて道路・建物の表示倍率は約2倍。
施設名・道路名を追加し、道路・建物・歩道・リフトの識別を改善。
地図上は全20地点のIDを重複なく掲載。A以外の店舗・観光スポットは省略していません。
一覧の文字サイズ・元JSON・イベント情報・集合欄は維持しています。

Web版QRを右上ヘッダーに移動し、読み取り先URLを再確認。
右下の集合枠は142×38ptから142×89ptに拡大（約2.3倍の面積）。
集合場所・集合時刻の値は引き続き空欄。紙面とPDFタイトルから「改訂稿」を削除。

上部の「昼食・カフェ・お土産・観光・イベント」を削除し、日付・時間をタイトル下に揃えて14ptに拡大。
